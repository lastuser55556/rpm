## Как забрать папку и как сдать

Папка `lesson_02` появилась в шаблоне после того, как вы завели свой
репозиторий. Забрать её проще всего кнопками: на GitHub в шаблоне
**Code → Download ZIP**, распаковать и положить папку `lesson_02` к себе
в проект.

Работа коммитится прямо в `main` и отправляется на GitHub, отдельная ветка
и Pull Request не нужны:
[коммиты](https://github.com/1DARKle1/backend-DARKle/blob/24a9e408967854751c4c154b6b1645232b3565e5/docs/git/README.md#3-изменения-и-коммиты) ·
[отправить на GitHub](https://github.com/1DARKle1/backend-DARKle/blob/24a9e408967854751c4c154b6b1645232b3565e5/docs/git/README.md#отправить-на-github).
