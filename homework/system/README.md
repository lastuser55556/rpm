# Системное программирование

Программа передаёт путь к файлу дочернему процессу, получает размер через стандартный вывод и возвращает код завершения. Имя передаётся отдельно от программы, поэтому пробелы в пути сохраняются и командная оболочка для запуска не нужна.

```sh
python3 main.py README.md
python3 main.py does-not-exist
```

Коды: 0 — размер получен; 2 — ошибка аргументов или нет файла; 3 — вышел таймаут; 4 — ошибка запуска или чтения метаданных в дочернем процессе. При таймауте subprocess завершает процесс и ждёт его выхода. В проверке использовал файл с пробелом в имени, отсутствующий путь и практически нулевой таймаут.
