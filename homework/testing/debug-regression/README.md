# Отладка и регрессионная проверка

**Дефект.** В учебной записи на шиномонтаж один интервал рассчитан на четыре автомобиля. При сравнении `len(requests) > 4` пятая заявка ошибочно принимается.

**Воспроизведение.** Для 09:00 последовательно отправить ID 0, 1, 2, 3 и 4. Ожидание: первые четыре приняты, ID 4 отклонён. При исходном условии пятая заявка проходила: перед вставкой длина равна 4, а выражение `4 > 4` ложно.

**Отладка.** До вызова add длина равна 4. Это значение можно посмотреть, поставив точку остановки на проверку вместимости. Исправил проверку на `>= 4`. Регрессионный тест также проверяет освобождение места при отмене, независимость интервалов, повторный ID и отмену отсутствующей записи.

Запуск: `python3 -m unittest -v`. Все три теста прошли.
