# Виды ошибок и методы отладки

| Вид | Пример | Как найти |
|---|---|---|
| Синтаксическая | Пропущено двоеточие после if | Запустить проверку синтаксиса, открыть строку из SyntaxError. |
| Во время выполнения | В расчёт передано количество 0 | Проверить traceback и значения аргументов. Допустимые границы описать в функции и тестах. |
| Логическая | При скидке 10% расчёт берёт 10% цены вместо 90% | Сверить с ручным расчётом, поставить точку остановки перед возвратом и проверить коэффициент. |

Пример логической ошибки воспроизвёл на 3 товарах по 49,90 рубля. Без скидки стоимость составляет 149,70. При ошибочной формуле с коэффициентом 0,10 получается 14,97. В формуле исправил коэффициент на 0,90, результат — 134,73. Для половины копейки зафиксировал округление вверх. Тесты также проверяют полную скидку и неверные параметры.

Запуск в папке работы: `python3 -m unittest -v`.
