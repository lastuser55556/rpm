# Разработка программных модулей

На примере отчёта кафе разделил расчёт, форматирование и точку входа. Расчёт принимает список цен в копейках и возвращает целую сумму. Форматирование получает готовое число, а main связывает модули и пишет результат в консоль.

```text
main → calculator
main → report
```

Расчёт можно проверить отдельно: пустой список даёт 0, отрицательная цена вызывает ValueError. Форматирование выводит две цифры после точки. Цены в целых копейках позволяют суммировать их без округления float.

Команда `python3 main.py` выводит `Итого: 256.50 руб.`.
