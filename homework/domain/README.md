# Доменные ошибки и управление ресурсами

Импорт продаж из CSV. Формат заголовка — `sale_id,amount_kopecks`. Пустой или повторный идентификатор и неположительная сумма нарушают правила предметной области, поэтому дают InvalidSale. Отсутствующий файл — ошибка ввода-вывода FileNotFoundError. Код, который вызывает импорт, может различить эти два случая.

Контекстный менеджер закрывает файл и при нормальном завершении, и при исключении. Ошибка преобразования числа сохраняется как причина InvalidSale, а сообщение содержит номер строки без вывода содержимого файла. Частичная сумма наружу не возвращается.

Проверил корректную сумму, повторный идентификатор, отсутствующую сумму, неверный заголовок, неположительную сумму и отсутствующий файл.
